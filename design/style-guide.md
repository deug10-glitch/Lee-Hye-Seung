# 스타일 가이드

## 느낌
생기있다 · 친근하다 · 가볍다
- 이유: 마스코트와 함께하는 서비스이고, 함께 플레이(P3·P4)·모바일 캐주얼(P5·P6) 사용자에게 탐색이 가볍고 즐겁게 느껴지도록 (팀 선택)

## 색
| 이름 | 코드 | 쓰는 곳 |
|---|---|---|
| 주 색 (파랑) | #3366FF | 주요 버튼, 선택된 칩·탭, 링크 (흰 글자 대비 충분) |
| 강조 색 (코랄) | #E4694C | 홍보 라벨, "확인 중" 표시, 마스코트·작은 강조. **흰 글자를 올리지 않음** (대비 부족) → 코랄 위에는 진한 글자 |
| 배경 | #FFFFFF | 화면 바탕 |
| 면 | #F4F6FB | 조건 패널, 정보 상자 |
| 글자 | #1D1D1F | 본문 |
| 보조 글자 | #55555C | 설명, 라벨 (흰 배경 대비 약 7:1) |
| 선 | #E3E5EC | 테두리, 구분선 |
- 색 이유: (팀 확인 필요) — 코랄은 #ED846D와 #E4694C 중 파랑과 어울리고 덜 연한 #E4694C로 정함

## 글자 크기 (둥글고 친근한: 굵은 제목 + 넓은 줄 간격)
| 단계 | 크기 | 굵기 |
|---|---|---|
| 큰 제목 | 28px | 800 |
| 제목 | 20px | 700 |
| 본문 | 15px | 400, 줄 간격 1.6 |
| 보조 | 13px | 400 |
- 글꼴: 기본 글꼴 (Apple SD Gothic Neo, 맑은 고딕)

## 모양
- 모서리: 카드·패널 16px, 버튼·입력칸 12px, 칩 999px(알약)
- 버튼: 높이 48px(작은 버튼 44px). 주 버튼 = 파랑 바탕 흰 글자, 보조 버튼 = 흰 바탕 선
- 화면: PC 웹 1200px

## 기본 부품
버튼(.btn, .btn-line), 입력칸(.input), 칩(.chip), 탭(.tab), 카드(.card), 배지(.badge, .badge-accent), 상단 바(.topbar), 정보 상자(.box)
