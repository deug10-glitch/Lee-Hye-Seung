# 스타일 가이드

## 느낌
신나다 · 생생하다 · 트렌디하다
- 이유: 게임을 고르는 일이 놀이처럼 느껴지게 (팀 결정, 이전 방향 "생기있다 · 친근하다 · 가볍다"에서 변경 — 팀 전체 합의 필요)

## 색
| 이름 | 코드 | 쓰는 곳 |
|---|---|---|
| 주 색 (보라) | #6C3BFF | 주요 버튼, 선택된 칩·탭, 링크, 로고 (흰 글자 대비 충분) |
| 주 색 진하게 | #5326E0 | 주 버튼 눌림·마우스 올림, "확인 중" 글자 |
| 강조 색 (라임) | #C6FF3D | 홍보 라벨, 마스코트, 추천 이유 띠. **글자색으로 쓰지 않음** (흰 배경에서 거의 안 보임) → 라임 위에는 진한 글자 #1D1D1F |
| 배경 | #FFFFFF | 화면 바탕 |
| 면 | #F5F3FF | 조건 패널, 정보 상자 (연보라) |
| 글자 | #1D1D1F | 본문 |
| 보조 글자 | #55556A | 설명, 라벨 (흰 배경 대비 약 7:1) |
| 선 | #E2DEF5 | 테두리, 구분선 |
| 배지 | 바탕 #EEE8FF / 글자 #4A22C9 | 플랫폼·조건 배지 |
- 색 이유: 보라·라임은 게임에서 많이 보는 색이라 한눈에 게임 서비스로 보여요 (팀 선택)

- 글꼴: 기본 글꼴 (Apple SD Gothic Neo, 맑은 고딕)

## 모바일 보정 (2026-11-27 점검에서 추가)
- 모바일 큰 제목: 24px / 800 (PC 28px은 폰에서 줄바꿈이 많아서)
- 작은 정보 글자: 12px (배지, 결과 카드 정보표, 입력칸 라벨에만)
- 챗봇 말풍선: 모서리 18px (말하는 쪽 아래 모서리만 4px), 마스코트 = 면 색, 나 = 주 색
- 점선 상자 테두리: 연보라 #B9A6FF (정보 보정 요청처럼 "참여해 주세요" 상자)
- 적용된 조건 태그(.tag): 배지 색, 높이 44px, 누르면 조건이 빠짐

## 조건 필터 (2026-11-27 추가)
- 조건을 6묶음으로 나눔: 비용(하나만 선택: 무과금 가능 · 1만 · 3만 · 5만 · 10만 원 이하 · 10만 원 이상) · 시간 · 광고 · 접속 · 함께 플레이 · 취향 · 난이도
- 필터 바(.fbar): 가로로 미는 알약 버튼. 고른 게 있으면 연보라 바탕 + 고른 이름(여러 개면 "취향 2")
- 바텀시트(.fs): 아래에서 올라오는 조건 창. 위 탭으로 묶음을 바꾸고, 체크박스 모양 카드 2열로 고름. 아래 "초기화" + "N개 결과 보기"

## 마스코트 (2026-11-27 추가)
- 이름: 뭉픽 (뭉실뭉실 + Gempick의 "픽")
- 앱에는 2D 버전을 파스텔 라벤더로 칠해서 씀 (`design/mascot/l_` 파일). 3D 버전은 `design/mascot/3d/`에 보관. 2D 원본은 `design/mascot/`
- 팀이 만든 강아지 마스코트 (`design/mascot/`): 흰 몸 + 보라 귀·줄무늬, 2D 선화. 원본은 파랑, 앱 톤에 맞춘 보라판은 `p_` 파일
- 표정 쓰는 곳: 머리 아이콘 = 마스코트 버튼·챗봇 프로필 / 윙크 = 2.0 제목 옆 / 생각 중 = 챗봇이 대답을 기다릴 때 / 신남 = 맞는 게임을 찾았을 때 / 슬픔 = 결과 없음
- 마스코트 색: 귀·줄무늬·목걸이는 파스텔 라벤더, 외곽선은 원래 진한 남색 (색 후보 비교: `color-options.png`의 ③). 프로필은 원 틀 없이 머리만 잘라 그대로 씀 (`p_head.png`)

## 모양
- 모서리: 카드·패널 16px, 버튼·입력칸 12px, 칩 999px(알약)
- 버튼: 높이 48px(작은 버튼 44px). 주 버튼 = 보라 바탕 흰 글자, 보조 버튼 = 흰 바탕 선
- 화면: 모바일 390px (2026-11-27 PC 웹에서 변경, 와이어프레임은 PC 기준이라 화면을 세로로 다시 배치)
