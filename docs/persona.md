# 퍼소나

> 출처: 팀원 8주차 개인과제 "페르소나 제작과정" PDF (2026-11-27 업로드). 인터뷰 카드 P1~P9의 행동변수 점도표로 도출. 아래 "예상 행동"은 인터뷰 특징을 바탕으로 한 가설이며 실제 관찰 결과가 아니다.

## 행동변수 (5개)
1. 선택 전 확인 정도: 간단한 소개만 보고 바로 해본다 ↔ 영상·리뷰를 충분히 확인하고 고른다
2. 게임 선택 시 고려 대상: 내 취향과 이용 조건 중심 ↔ 함께할 사람들의 조건까지 맞춰 고른다
3. 선택 실패 후 탐색 방식: 기존 게임이나 다른 활동으로 돌아간다 ↔ 다른 새로운 게임을 계속 찾아본다
4. 평가 판단 기준: 전반적인 호평·혹평 중심 ↔ 내 조건과 취향에 맞는 구체적 평가 중심
5. 게임 구매비용 수용 방식: 무과금으로 즐길 수 있는 게임 우선 ↔ 조건에 맞으면 유료 게임 구매도 검토

## A. 꼼꼼히 확인하고 함께할 조건을 맞추는 유형 (P1, P3) — 주 타깃
- 확인된 특징: 영상·리뷰 확인, 동행자의 인원·사양·가격 고려
- 예상 행동: 함께할 인원·사양·예산 입력 → 추천 이유와 구체적 리뷰 확인 → 친구들과 조건 비교 → 조건이 맞으면 구매·플레이 검토
- 실패하면: 맞는 게임이 없으면 기존 게임으로 돌아간다
- 무엇이 힘든가: 함께할 사람마다 인원·기기 사양·예산 조건이 달라 게임을 고르기 어렵고, 영상과 리뷰로 적합성을 확인하는 데 많은 시간이 든다.

## B. 부담을 확인하고 가볍게 즐기는 유형 (P5, P6)
- 확인된 특징: P5 시간·접속 부담, P6 광고·네트워크 제약
- 예상 행동: 자신이 피할 조건 입력 → 시간·과금·광고 등 해당 정보 확인 → 조건에 맞는 후보 선택 → 실제 이용 부담이 크면 중단
- 무엇이 힘든가: 출석·퀘스트가 지속적인 접속을 요구하거나 강제 광고·인터넷 연결이 이용을 제한해, 짧은 시간에 부담 없이 즐기기 어렵다.

## C. 필요한 만큼 확인하고 함께할 게임을 고르는 유형 (P4, P9, 잠정)
- 확인된 특징: 확인 범위 제한, 함께할 사람 고려
- 예상 행동: 함께할 상황과 취향 입력 → 필요한 핵심 정보만 확인 → 친구들과 할 게임 선택 → 맞지 않으면 기존 게임·다른 활동으로 돌아감
- 무엇이 힘든가: 정보량이 많아 필요한 내용을 찾기 어렵고, 게임 완성도가 높아도 함께할 사람들의 취향이 달라 고르기 어렵다.
