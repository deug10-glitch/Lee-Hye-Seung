# 자료 지도

## 서비스
- 이름: Gempick (겜픽, 게임픽) — 가상 이름
- 컨셉: PC·콘솔·모바일 게임을 한곳에 모으고, 시간·과금·광고·인원·기기 같은 상황 조건을 고르면 맞는 게임만 추려 보여주는 반응형 웹 플랫폼

## 핵심 기능 (기획서 그대로)
1. 조건 옵션 (주 기능): 비용·시간, 광고·접속 조건, 함께 플레이, 취향·난이도 4묶음
2. 필수 표기 원칙: 옵션으로 만들기 어려운 정보는 게임 설명에 반드시 표시, 정보가 없으면 "확인 중" + 보정 요청 버튼
3. 결과 화면: 아이콘·이미지가 큰 카드형, 플랫폼 배지와 핵심 조건 요약
4. 내 기기 설정: 가입 시 선택사항, 나중에 수정 가능, 전체·모바일·PC·콘솔 탭
5. 부가 기능: 취향 학습 개인화(추천 이유 표시), 캐릭터 챗봇 AI 탐색(이름 있는 마스코트)
