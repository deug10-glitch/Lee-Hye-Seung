# 플로우로 기획 다시 점검하기

기준: Gempick 기획서(claude.ai 문서) 4장 핵심 기능, 3장 타깃 사용자 / `flow/flow.md` 플로우 1 (친구들과 함께할 게임 찾기)

## 1. 기능에서 플로우로
| 핵심 기능 | 어느 플로우, 몇 단계에 나오나 | 어느 화면에서 | 판정 |
|---|---|---|---|
| 조건 옵션 4묶음 (주 기능) | 플로우 1, 1단계 (함께 플레이·비용 묶음만 사용) | 조건 선택·결과 (2.0) | 들어감 |
| 결과 화면 (카드형, 플랫폼 배지, 조건 요약) | 플로우 1, 1~2단계 | 조건 선택·결과 (2.0) | 들어감 |
| 필수 표기 원칙 ("확인 중" + 보정 요청) | 플로우 1, 3단계 갈림길 ① | 게임 상세 (2.1) | 들어감 |
| 이용자 보정 (데이터 전략) | 플로우 1, 3단계 갈림길 ① | 게임 상세 (2.1) | 들어감 |
| 스토어 연결 (제휴 수수료) | 플로우 1, 3단계 | 게임 상세 (2.1) | 들어감 |
| 마스코트 챗봇 (부가) | 플로우 1, 1단계 갈림길 (결과 0개) | 마스코트 챗봇 (3.0) | 들어감 (갈림길에서만) |
| 내 기기 설정 | 어느 플로우에도 없음 | 1.0, 5.0 (와이어프레임만 있음) | 약함 |
| 취향 학습 개인화 · 추천 이유 (부가, 2단계) | 플로우에 단계로 없음 | 게임 상세 (2.1)의 "추천 이유" 상자 | 약함 |
| 개발사 홍보 플랜 ("홍보" 라벨) | 플로우에 없음 | 조건 선택·결과 (2.0) 카드 | 약함 |

## 2. 플로우에서 기획서로 (기획서에 없는 것)
| 플로우의 행동·화면 | 기획서와의 관계 |
|---|---|
| 4.0 로그인 (선택형, 게스트 가능) | 기획서에 로그인·게스트 구분이 없음 |
| 결과 0개일 때 챗봇으로 안내 (플로우 1, 1단계 갈림길) | 기획서는 챗봇을 부가 기능으로만 적고, 결과 없음 처리는 없음 |

## 3. 퍼소나로 다시 보기 (함께 플레이 중심, P3)
| 인터뷰의 불편 | 플로우에서 | 상태 |
|---|---|---|
| 5명이 동시에 할 수 있는 게임이 적다 (P3 Q2) | 1단계 "5인 이상" 칩 | 해결 |
| 3~4만 원 게임을 같이 사자고 하기 부담 (P3 Q6) | 1단계 비용(가격대) 칩, 3단계 가격 확인 | 해결 |
| 크로스플랫폼 지원 여부가 확실히 표시되길 원함 (P3 Q11) | 1단계 크로스플랫폼 칩, 2.1 배지 | 해결 |
| 인원수·평균 사양을 넣으면 3개 정도로 압축 추천 (P3 Q10) | 결과 0개 갈림길의 챗봇에서만 3개 추천 | 일부 |
| 친구들 각자 컴퓨터 사양이 다름 (P3 Q6) | 3단계에서 권장 사양 확인, 그러나 MVP 후순위라 "확인 중"이 많을 것 | 남음 |
| 매칭 시스템이 엉망이라 방을 못 잡음 (P3 Q8) | 매칭 안정성은 MVP 후순위 옵션, 플로우에 없음 | 남음 |

## 4. 팀 결정
| 항목 | 결정 | 이유 |
|---|---|---|
| 내 기기 설정 (약함) | 플로우 2 "처음 온 사용자가 기기를 고르고 첫 게임 찾기"를 새로 그린다 (4.0 → 1.0 → 2.0 → 2.1) | (이유 확인 필요) |
| 취향 학습 개인화 (약함) | 로그인 사용자만 제공, 게스트는 조건 일치 이유만. 기획서 4-4에 명시함 (2026-11-20 변경 기록) | 로그인 이점을 분명히 하고, 게스트는 정보를 기억하지 못하므로 |
| 개발사 홍보 플랜 (약함) | 그대로 둔다 | (이유 확인 필요) — 선택지 설명: 수익 모델이고 3단계 로드맵 기능이라 플로우에 없어도 됨 |
| 선택형 로그인 (기획서에 없음) | 기획서는 두고 플로우 메모로만 남긴다 | (이유 확인 필요) |
| 결과 0개일 때 챗봇 안내 (기획서에 없음) | 기획서 4-4에 "조건에 맞는 게임이 없으면 마스코트 챗봇이 대화로 조건 조정을 돕는다" 추가 (2026-11-20 변경 기록) | (이유 확인 필요) |
| P3 매칭 불편 (퍼소나에게 남음) | 매칭 안정성을 MVP 우선 구현으로 올림. 결과 0개면 조건을 포기시키지 않고, 고른 조건 중 일부를 만족하는 매칭 가능한 관련 게임을 먼저 추천하고 챗봇은 보조로 둠 | 핵심 퍼소나 P3의 매칭 불편 해결, 탐색 포기 방지 |
